# Starcraft 2 Tournament Form

Aplicación Vue 3 + Tailwind CSS para el formulario de registro del proyecto Survey Form de freeCodeCamp.

Los comandos se ejecutan desde la raíz del repositorio:

```bash
npm install
npm run dev
npm test
npm run lint
npm run typecheck
```

El documento `index.html` conserva el bundle oficial de pruebas de freeCodeCamp y `tests/survey-form.spec.js` replica sus requisitos estructurales para validarlos en local.
